# DIXX Co. - Premium Men's Underwear

Modern e-commerce website for DIXX Co., featuring premium men's underwear collections with a bold brand voice and complete checkout system.

## Features

- 🛒 Full shopping cart system
- 💳 Payment processing (Authorize.Net & Zelle)
- 💰 Special bundle pricing (5 pairs for $99)
- 📱 Responsive design
- 🎨 Modern, premium UI/UX

## Collections

1. **Original Dixx** - Classic everyday comfort

5. **Athletic DIXX** - Performance underwear
6. **The Anaconda** - Extra room for the well-endowed

## Tech Stack

- HTML5, CSS3, JavaScript
- Authorize.Net payment integration
- Zelle payment option
- LocalStorage for cart persistence
